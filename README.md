# 🧠 To-Do App

Une application **To-Do List** interactive construite avec **React** et **Tailwind CSS**.  
Elle permet d’ajouter, filtrer, marquer, supprimer et trier les tâches par date, importance ou statut.

## 🧩 Fonctionnalités

✅ Ajouter une tâche avec une date  
✅ Marquer une tâche comme **terminée**  
✅ Marquer une tâche comme **importante**  
✅ Trier les tâches par **date**, **importance** ou **statut**  
✅ Supprimer une tâche  
✅ Enregistrer automatiquement les tâches dans le **LocalStorage**  
✅ Interface moderne avec **Tailwind CSS**  
✅ Affichage sous forme de **cards**  

---

## 🛠️ Technologies utilisées

- ⚛️ **React.js**
- 🎨 **Tailwind CSS**
- 💾 **LocalStorage**
- ⚙️ **Vite** ou **Create React App**
